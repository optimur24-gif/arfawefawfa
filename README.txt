ТЕЛЕГРАМ-БОТ ПО ОСТЕОЛОГИИ

БАЗА

103 вопроса по костям. Все остальные разделы удалены.
Исходные ID, тексты, варианты и ключи сохранены.
Отправьте /start после запуска.
Постоянный хостинг этим архивом не предоставляется.

ОБЫЧНАЯ ТРЕНИРОВКА

Начать — случайные вопросы без повторов в сессии либо продолжение текущей.
Выберите один/несколько вариантов, затем «Проверить». Верен точный набор букв.
Бот показывает правильно выбранные, пропущенные и лишние варианты.
Повторная проверка не создаёт второй ответ; старые кнопки не принимаются.
Стоп — пауза; Продолжить возвращает вопрос и выбор после перезапуска.
Заново начинает новую сессию, а для списка/экзамена сохраняет исходный режим.
Назад / сброс сессии не удаляет личные списки, историю ошибок и прогресс.

ЗАУЧИВАНИЕ И НЕСКОЛЬКО СПИСКОВ

Мои списки — создание, переключение, переименование и удаление именованных наборов.
Например, «Кости», «К экзамену», «Сложное». У каждого пользователя свои списки.
Прежний список перенесён без потери вопросов, выбора и позиции карточки.
Активный список отмечен в меню; ⭐ добавляет вопрос именно в него.

Новый список: задайте имя и количество случайных заданий, например30.
В Заучивании можно заполнить активный список заново, добавить ещё30 или своё
количество от1 до103. Новые задания не повторяют уже добавленные:30+30=60.
Если осталось меньше вопросов, добавятся все оставшиеся.
⭐ В заучивание под любым вопросом сохраняет его вручную. Повторного дубля нет.
Список — просмотр заданий и TXT с ответами. Учить — карточки с «Показать ответ».
Просмотр карточки не записывается как правильный/неправильный ответ.
Проверить себя — тест по этому списку с записью результатов.
Добавление в тот же список расширяет текущий тест без повторов.
Смена активного списка ставит старый тест на паузу; Продолжить возвращает его
с исходным набором. Название списка видно в вопросе.
Сброс/удаление списка сохраняет историю и прогресс. Тест удалённого списка отменяется.

ПОВТОРЕНИЯ, ПРОГРЕСС И НАПОМИНАНИЯ

После ошибки повторение назначается на завтра. После правильных ответов в разные
UTC-дни интервалы составляют3,7,14 дней. Много ответов в один день не ускоряют серию.
Ошибка сбрасывает серию, но не удаляет историю.
Новый — ещё нет проверенных ответов; Повторить — серия меньше трёх дней;
Выучен — три правильных ответа в разные дни без ошибки между ними.
Выученный вопрос возвращается через14 дней для поддержания знаний.
Повторить сегодня запускает сессию по наступившим/просроченным повторениям.
Прогресс показывает общий результат и результат активного списка.

Напоминания по умолчанию выключены. Пользователь включает их своей кнопкой.
Не более одного сообщения за UTC-день после09:00UTC, только если есть повторения.
Выключить можно той же кнопкой. Старые ответы используются для начального прогресса.

ЭКЗАМЕН

45 случайных вопросов за45 минут,45 без таймера или30 без таймера.
Во время экзамена бот подтверждает сохранение выбора, но не раскрывает результат,
ключ или разбор. Ответы до завершения не видны в статистике, ошибках, прогрессе
и админской выгрузке. После завершения результаты публикуются вместе.
Процент считается от всего набора; пропущенные задания учитываются.
Пороги:91% отлично,81% хорошо,71% удовлетворительно.
Есть разбор каждого ответа и добавление неверных/пропущенных заданий в активный список.

Таймер хранит дату окончания UTC, переживает перезапуск и продолжает идти на паузе.
По окончании времени ввод не принимается; результат отправляется в пределах примерно
20 секунд. «Завершить экзамен» заканчивает его раньше.
Результат доступен по своим кнопкам после новой сессии; чужой архив не открывается.
Повторное добавление ошибок не дублирует вопросы.

ОШИБКИ, СТАТИСТИКА И ЗАМЕЧАНИЯ

Мои ошибки — личный список частых ошибок, сортировка по числу/доле, страницы и TXT.
Правильный ответ в будущем не удаляет историческую ошибку.
Темы — тренировка по выбранному разделу без повторов.
⚠️ Ошибка в задании — замечание к вопросу для администратора. Текущий вопрос
и его кнопки сохраняются. Замечания автоматически не меняют текст или ключи PDF.

Администратор @Timur0_15 видит @username/TelegramID, статистику каждого,
частые ошибки, CSV и замечания, включая полный текст. Роль проверяется на всех кнопках.
Первая проверенная учётная запись с usernameTimur0_15 привязывается по ID.
Привязка остаётся после изменения username. Числовой ADMIN_ID в .env имеет приоритет.
/id показывает ваш ID. Бот работает в личных чатах.

КОМАНДЫ

/start /help — меню; /quiz — тренировка; /learn — заучивание; /lists — списки;
/due — повторить сегодня; /progress — прогресс; /topics — темы; /exam — экзамен;
/reminders — напоминания; /resume — продолжить; /again — заново; /stop — пауза;
/back — сброс сессии; /mistakes — ошибки; /stats — статистика; /id — ID;
/admin /reports — статистика/замечания, только для администратора.

САМОСТОЯТЕЛЬНЫЙ ЗАПУСК

Python3.10+. Скопируйте .env.example в .env и укажите BOT_TOKEN от @BotFather.
При желании задайте ADMIN_ID. В терминале из папки скрипта:
python -m pip install -r requirements.txt
python bot.py --check
python bot.py

Для bot.py рядом нужны questions.txt, answer_helpers.py, features.py, feature_ui.py.
bot_single.py содержит модули и базу внутри одного файла, отдельный TXT ему не нужен.
Запуск: python bot_single.py. Используйте один экземпляр с одним токеном.
Приватный токен действующего запуска в архив/скрипт не включён.

ПАМЯТЬ И ЗАПУСК

Подробные варианты запуска описаны в README.md.
Локально progress.sqlite3 создаётся рядом со скриптом; путь задаётся DB_PATH.
В Docker прогресс хранится в постоянном volume progress.
Миграции сохраняют прежние таблицы, списки и ответы.
Временный запуск через GitHub Actions не сохраняет историю между запусками.

ОБНОВЛЕНИЕ И ПРОВЕРКИ

questions.txt — JSON UTF-8. Не меняйте ID: на них ссылается история.
source_options/source_key — исходные варианты/ключ; source_faithful=true включает
их отображение. correct — буквы ключа; topic — тема. В базе все enabled=true.
После правок перезапустите бот. python build_release.py пересобирает встроенный
bot_single.py и ZIP без приватных файлов.
python bot.py --check — проверка базы/лимитов без токена и сети.
python -m unittest discover -v — проверки функций, миграции и обработчиков без сети.
Отдельному extract_questions.py для повторного извлечения нужен PyMuPDF;
самому боту он не требуется.
