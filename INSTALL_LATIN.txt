ВАРИАНТ 1. Если хостинг запускает python bot.py

Остановите текущий экземпляр бота на хостинге.
В папке, где находится прежний bot.py, замените из архива:
- bot.py
- Dockerfile (если запуск производится через Docker)
- .dockerignore (если запуск производится через Docker)
- build_release.py (только если самостоятельно собираете bot_single.py/ZIP)

В ту же папку ДОБАВЬТЕ:
- latin_cards.py
- latin_ui.py
- latin_data.json

Существующие answer_helpers.py, features.py, feature_ui.py и questions.txt
нужны рядом с bot.py. Они входят в архив и не требуют изменения для обновления.
Не перезаписывайте свой .env, progress.sqlite3, runtime/data или постоянный том.
Токен и личные данные в архив не включены.

Зависимости прежние:
python -m pip install -r requirements.txt

Проверка:
python bot.py --check

Команда запуска прежняя:
python bot.py

Docker: выполните повторную сборку образа и развёртывание.
При Docker Compose команда: docker compose up -d --build
Базу данных храните в постоянном томе; не используйте docker compose down -v.

ВАРИАНТ 2. Если хостинг запускает python bot_single.py

Замените только bot_single.py одноименным файлом из архива.
В нем встроены вопросы по остеологии, латинская база и модули карточек.
Отдельные latin_cards.py, latin_ui.py и latin_data.json для этого варианта не нужны.
Установленные зависимости и переменная BOT_TOKEN по-прежнему необходимы.
Не меняйте DB_PATH: так сохранится прежняя история.
Проверка: python bot_single.py --check
Запуск: python bot_single.py

Если хостинг получает код из GitHub, внесите перечисленные замены и новые файлы
в корень репозитория optimur24-gif/arfawefawfa, ветка main.
Затем выполните повторное развёртывание (Redeploy) на хостинге.
Файлы из папки anatomy_bot в архиве должны находиться в той же папке,
где на хостинге уже лежит запускаемый bot.py, а не во вложенной папке anatomy_bot/anatomy_bot.

После перезапуска отправьте /start, затем нажмите «Латынь», или отправьте /latin.
Нельзя одновременно запускать bot.py и bot_single.py с одним токеном.

Про данные
Словарные формы и правила перенесены из присланного PDF без замены терминов.
Строка enamelum, enameli n сохранена в форме, указанной в PDF.
Ударения из фото не используются как часть тестового ответа.
Авторство изречений не проверяется: тестируется само выражение и перевод.
Четыре варианта Prognosis вынесены в отдельные карточки.
