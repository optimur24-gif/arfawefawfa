# Telegram-бот: остеология и латынь

103 вопроса только по костям. Остальные разделы удалены; исходные ID, тексты, варианты и ключи сохранены.

Функции: тренировка, заучивание, личные списки, экзамен, ошибки, статистика, повторения и напоминания. Полное описание команд: [README.txt](README.txt).

## Латынь

Кнопка «Латынь» и команда `/latin`: 57 слов с полными словарными формами,
переводом, родом, склонением, правилами и исключениями; 30 крылатых
и 17 медицинских выражений. Карточки работают в обе стороны; тесты
проверяют перевод, полную форму, Gen. sg. и род. Позиция и личные результаты
сохраняются в той же SQLite отдельными таблицами.

Инструкция замены файлов: [INSTALL_LATIN.txt](INSTALL_LATIN.txt).
Временный запуск на GitHub отключён; бот запускается на вашем хостинге.

### Латынь, 43 параграф

Отдельная кнопка «📖 Латынь, 43 параграф» в главном меню и команда `/latin43`.
В разделе 66 слов из PDF: 44 прилагательных и 22 существительных.
Карточки в обе стороны показывают три формы m/f/n либо Nom./Gen. и род,
полную словарную форму, правила окончаний и особенности слов на `-er`.
Доступны тесты на перевод, полную форму, мужскую, женскую и среднюю формы;
для существительных — Gen. sg. и род. Тесты на формы прилагательных включают
44 слова, тесты на род и Gen. существительных — 22; перевод и полная форма — все 66.
Памятка «Правила: роды и окончания» находится внутри раздела.
Позиция, проверенные ответы и личные результаты сохраняются в SQLite;
«Продолжить §43» возвращает к незавершённой сессии.

## Постоянный запуск на сервере с Docker

Скопируйте `.env.example` в `.env`, укажите `BOT_TOKEN` и выполните:

```bash
docker compose up -d --build
docker compose logs --tail=30 bot
```

Бот перезапускается автоматически; прогресс хранится в постоянном Docker volume `progress`. Обновление: повторить `docker compose up -d --build`. Остановка: `docker compose down` (без `-v`, чтобы сохранить данные).

## Локальный запуск

Python 3.10+:

```bash
python -m pip install -r requirements.txt
python bot.py --check
python bot.py
```

`bot_single.py` содержит код и вопросы в одном файле. Для него также нужны установленные зависимости и токен в окружении или `.env`.

## Проверки

```bash
python -m unittest discover -q
python bot_single.py --check
```

Токен и персональные базы данных в репозиторий не включаются.
